## 🏢 개발 환경

- 개발도구: IntelliJ IDEA · VS Code
- 언어: Java 17 · JavaScript · Python
- 빌드도구: Gradle · Vite
- 개발
  * Spring Boot 4.1.0
  * Spring Security · JWT
  * Spring Data JPA
  * Spring Data Neo4j
  * Spring Data Redis
  * Spring WebSocket (STOMP)
  * React 19
  * FastAPI · LangGraph
- 데이터베이스
  * PostgreSQL
  * Neo4j
  * Redis
- 최적화 엔진
  * NVIDIA cuOpt
- ERD
  * ERDCloud
- Object Storage
  * AWS S3
- 배포
  * Docker · AWS
